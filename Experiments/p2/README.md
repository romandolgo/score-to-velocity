# Пара B: интеграторы (П0) и Score SDE (П2)

## Состав
- `common/` — общий модуль проекта:
  - `integrators.py` — Эйлер для ODE, Эйлер–Маруяма для SDE (П0, пара B);
  - `sde.py` — VE- и VP-SDE: f, g, α(t), std(t), приор (П2);
  - `samplers.py` — обратное SDE, probability flow ODE, log-likelihood через PF ODE (точная дивергенция и Хатчинсон). Пригодится в П4;
  - `oracle.py`, `nets.py`, `metrics.py` — временные версии; пары A и C заменят их своими.
- `p2_score_sde.ipynb` — П2: обучение, качество vs NFE, log-likelihood. Выводы в конце.
- `p2_experiments.py` — все долгие вычисления П2. Ноутбук берёт готовые результаты из `checkpoints/` и `results/`, поэтому перезапускается за 1–2 минуты.
- `figures/` — рисунки, создаются при запуске ноутбука. В репозитории лежат два для постера:
  `p2_quality_vs_nfe.png` (ячейка раздела 2) и `p2_loglik_scatter.png` (ячейка раздела 3).

## Запуск
Из этой папки (нужны torch, numpy, matplotlib):

    jupyter notebook p2_score_sde.ipynb      # Run All

Пересчитать всё с нуля: удалить `checkpoints/` и `results/` и запустить ноутбук (около 30 минут на CPU),
или по частям из терминала — команды в начале `p2_experiments.py`.

## Главные цифры П2 (8 гауссиан, неравные веса; пол метрики SW1 ≈ 0.034)
| SW1 при NFE = 10 | SDE | ODE |
|---|---|---|
| VE | 0.13 | 0.32 |
| VP | 0.12 | 0.08 |

При NFE ≥ 100 все варианты на уровне пола метрики. Сеть и точный score оракула дают почти одинаковые кривые.

Log-likelihood через PF ODE: истинный NLL 1.908; сеть 1.909 (VE) и 1.920 (VP); корреляция с истинным log p 0.99.
С точным score поточечная ошибка 0.007 nat (VP, схема Эйлера) и 0.03 nat (VE, в основном приор вместо настоящего p_T).
Хатчинсон с одним вектором: поточечная ошибка 0.83 nat против 0.13 у точной дивергенции; разброс падает как 1/√K.

Random seed зафиксирован везде.
